#+TITLE: State Management & Timestamp Features Spec
#+DATE: [2026-01-08]
#+FILETAGS: :devlog:spec:gtd:agent:

* Context

orgx lacks timestamp awareness and state transition logging. Current commands (peek, get, find, set) can't support GTD workflow where items flow: INBOX -> BACKLOG -> devlog.

* Problem

Users maintain task flow across files but orgx can't:
1. Log state transitions (violates Org LOGBOOK convention)
2. Set timestamps/deadlines programmatically
3. Query by state or date range
4. Capture with proper metadata
5. Move items between files with state changes

This breaks LLM-human collaboration where agents should maintain audit trails.

* TODO State Model

#+BEGIN_SRC text
User's Emacs config states:

IDEA  - captured, not yet committed
TODO  - committed, actionable
PROJ  - container for subtasks
LOOP  - recurring task
STRT  - actively working (in-progress)
WAIT  - blocked on external dependency
HOLD  - paused by user decision
DONE  - completed successfully
KILL  - cancelled/abandoned

Transitions:
IDEA -> TODO -> STRT -> DONE
            |       |
          WAIT   HOLD
            |       |
          TODO   STRT
            |
          KILL
#+END_SRC

* Proposed Features

** F1: Automatic State Change Logging

When =orgx set REF --todo NEWSTATE= changes state:
- Parse current TODO state
- Append transition to LOGBOOK drawer
- Create drawer if missing

#+BEGIN_SRC org
* STRT Fix auth bug
:PROPERTIES:
:ID: abc123
:END:
:LOGBOOK:
- State "STRT"       from "TODO"       [2026-01-08 Thu 14:30]
- State "TODO"       from "IDEA"       [2026-01-07 Wed 09:15]
:END:
#+END_SRC

Edge cases:
- First state: log as =State "TODO" from "" [timestamp]=
- Same state: no-op (idempotent)
- =--no-log= flag: skip logging

** F2: Timestamp Management

New flags for =orgx set=:
#+BEGIN_SRC text
--scheduled DATE       Set SCHEDULED: <DATE>
--deadline DATE        Set DEADLINE: <DATE>
--created              Set :CREATED: property
--closed               Add CLOSED: [timestamp] (auto on DONE/KILL)
--no-log               Skip LOGBOOK state logging
#+END_SRC

Date input formats:
- ISO8601: =2026-01-08=, =2026-01-08T14:30=
- Relative: =today=, =tomorrow=, =+1d=, =+2w=, =-3d=
- Org format: =<2026-01-08 Thu>=

Auto-close: when state -> DONE or KILL, add =CLOSED: [timestamp]=

** F3: State-aware Queries

New =orgx find= flags:
#+BEGIN_SRC text
--todo STATE[,STATE...]     Filter by TODO state (comma-separated)
--after DATE                Items with timestamps after date
--before DATE               Items with timestamps before date
--scheduled-after DATE      SCHEDULED after date
--scheduled-before DATE     SCHEDULED before date
--deadline-after DATE       DEADLINE after date
--deadline-before DATE      DEADLINE before date
#+END_SRC

Examples:
#+BEGIN_SRC bash
orgx find "" --todo WAIT --in .                  # blocked tasks
orgx find "" --deadline-before today --in .      # overdue
orgx find "" --scheduled-after -7d --in .        # scheduled this week
orgx find "" --todo TODO,STRT --in ~/org/        # active items
#+END_SRC

** F4: Capture Command

#+BEGIN_SRC bash
orgx capture TEXT [--to FILE] [--todo STATE] [--tags T1,T2] [--scheduled DATE] [--deadline DATE]
#+END_SRC

If =--to= is omitted, uses =default_file= from config (default: =INBOX.org= in cwd).

Creates new heading at EOF:
#+BEGIN_SRC org
* IDEA Review Gemini API docs
:PROPERTIES:
:ID: auto-generated-uuid
:CREATED: [2026-01-08 Thu 14:30]
:END:
#+END_SRC

** F5: Promote/Refile Command

#+BEGIN_SRC bash
orgx promote REF --to FILE [--todo STATE] [--scheduled DATE] [--deadline DATE]
#+END_SRC

Moves heading between files with state transition logging:
#+BEGIN_SRC bash
orgx promote INBOX.org::ID:abc123 --to BACKLOG.org --todo TODO --yes
# Moved: INBOX.org::ID:abc123 -> BACKLOG.org::ID:abc123
# Logged: State "TODO" from "IDEA" [2026-01-08 Thu 14:30]
#+END_SRC

** F6: Log/History View

#+BEGIN_SRC bash
orgx log REF [--json] [--limit N]
#+END_SRC

Output:
#+BEGIN_SRC text
2026-01-08 Thu 14:30  STRT <- TODO
2026-01-07 Wed 09:15  TODO <- IDEA
2026-01-06 Tue 16:00  IDEA <- (created)
#+END_SRC

* Decisions

| Decision | Alternatives | Rationale |
|----------+--------------+-----------|
| LOGBOOK drawer for state history | Custom property | Org convention, Emacs compatible |
| Relative dates (+1d, +2w) | Only ISO8601 | Agent-friendly ("schedule in 3 days") |
| Auto-close on DONE/KILL | Manual only | Matches Emacs behavior, less toil |
| Capture appends at EOF | Insert by priority | Avoid disrupting structure, refile later |
| Preserve LOGBOOK on promote | Clear on move | Audit trail across file boundaries |
| ISO8601 in JSON output | Org format strings | Unambiguous for LLM parsing |

* Risks

| Risk | Mitigation | Status |
|------+------------+--------|
| Concurrent edits (Emacs + orgx) | Detect mtime change before write | Open |
| Large LOGBOOK (100+ entries) | --limit flag on log command | Open |
| State typos (STAT vs STRT) | Levenshtein suggest, require confirm | Open |

* Implementation Status

All features implemented in single iteration:

** Timestamp Support [DONE]
- pkg/orgtime: date parsing (ISO8601, relative, org format)
- --scheduled, --deadline, --created, --closed flags on set
- Timestamp fields in JSON output (Closed, Logbook in IR)

** State Logging [DONE]
- LOGBOOK drawer parsing (pkg/parser/org.go)
- State change logging in set command (auto on --todo change)
- --no-log escape hatch
- log command for history view

** Queries [DONE]
- --todo STATE,STATE (comma-separated) on find
- --after, --before, --scheduled-after/before, --deadline-after/before
- State/date filtering in matchesQuery

** Workflow Commands [DONE]
- capture command (creates heading with ID + CREATED)
- promote command (moves heading, logs state change)
- Config schema extended (StatesConfig, CaptureConfig)

** Not Yet Implemented
- Levenshtein state typo detection

** Timezone Support [DONE]
- Config: ~[timestamps] timezone = "Asia/Singapore"~
- All date operations respect configured timezone
- Falls back to system time.Local if not set or invalid

* Example Workflow

#+BEGIN_SRC bash
# Capture idea
orgx capture "Review Gemini API" --to INBOX.org --yes
# Created: INBOX.org::ID:abc123

# Promote to backlog with deadline
orgx promote INBOX.org::ID:abc123 --to BACKLOG.org --todo TODO --deadline +3d --yes
# Moved: INBOX.org::ID:abc123 -> BACKLOG.org::ID:abc123
# Logged: State "TODO" from "IDEA"

# Start work
orgx set BACKLOG.org::ID:abc123 --todo STRT --yes
# Logged: State "STRT" from "TODO"

# Check progress
orgx log BACKLOG.org::ID:abc123
# STRT <- TODO <- IDEA

# Complete
orgx set BACKLOG.org::ID:abc123 --todo DONE --yes
# CLOSED: [2026-01-08 Thu 15:45]
#+END_SRC

* Config Schema

#+BEGIN_SRC toml
# ~/.config/orgx/config.toml
[timestamps]
timezone = "Asia/Singapore"

[states]
keywords = ["IDEA", "TODO", "PROJ", "LOOP", "STRT", "WAIT", "HOLD", "DONE", "KILL"]
done_states = ["DONE", "KILL"]
auto_close = true

[capture]
default_file = "~/org/INBOX.org"
default_state = "IDEA"
#+END_SRC

* Gotchas

- LOGBOOK is a drawer (=:LOGBOOK:= at column 0), not a property
- Day-of-week in timestamps: computed from date, not parsed from input
- go-org uses 1-based line numbers, Go I/O uses 0-based
- Relative dates anchor to midnight in configured timezone (or system time.Local)
- Windows CRLF: detect and preserve on write
- Timezone: set ~[timestamps] timezone = "Asia/Singapore"~ in config, or uses system default
- capture/promote only support .org files (no markdown)
