* Decisions

| Decision | Alternatives | Rationale |
|----------+--------------+-----------|
| Graph is a command, not a graph/ dir | store graph.json in vault | derived data in a vault goes stale and lies; org-roam needs sqlite because Emacs is interactive — a CLI is not |
| .orgx/ marker + walk-up discovery | workspace config only | locality beats global default; zero-config inside the vault |
| Discovered vault outranks default workspace | reverse | being inside a vault is the stronger signal (the git model) |
| whiteboards/ scaffolded, no tooling | omit until tooling exists | owner's proposed layout; ARCHITECTURE.md says "reserved" honestly |
| flashcards = a page, not a dir | flashcards/ directory | one always-loaded page (the ihme pattern); a dir invites sprawl |
| org-roam daily/ detected, never migrated | migrate on init | never rewrite a vault we did not create |

* Risks

| Risk | Mitigation | Status |
|------+------------+--------|
| Machine path in git history (pre-public commits) | reveals nothing beyond public ihme-cli commits (same author); tip fixed | Accepted |
| Vault discovery changes behavior near stray .orgx dirs | marker must be a directory; -w/--root override | Open, low |
| whiteboards/ reserved with no tooling | documented as reserved | Open |
