* Decisions

| Decision | Alternatives | Rationale |
|----------+--------------+-----------|
| Author = =@name= entry tag (+ :ORGX_AUTHOR: on nodes) | property only; separate agent files | queryable with existing find --tag; agents share the human's files |
| Head-only scan in pkg/roam | full parse per file | node list over ~1k files stays ms-cheap |
| Workspace root IS the graph | new [roam] config section | ws add/use already existed; RoamDB field was already sketched |
| kind auto-derived from command path | per-command constants | zero drift, zero per-command edits |
| Envelope now (breaking) | keep bare arrays | pre-1.0 + private; versioned kinds prevent silent breaks later |
| find recurses on directories | keep flat glob | dailies invisible one level down read as "no matches" |

* Risks

| Risk | Mitigation | Status |
|------+------------+--------|

| Repo is private; no release automation | goreleaser + v0.2.0 when owner wants it public | Open |
