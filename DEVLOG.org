* Quick Context

orgx-cli: Context-efficient CLI for LLMs to work with Org and Markdown.

| Stack | Tech |
|-------+------|
| Language | Go 1.23+ |
| Parsers | go-org + goldmark |
| Pattern | gh-cli (noun-verb grammar) |
| Output | JSON (agents), text (humans) |

Core insight: LLMs have limited context. Every token counts.

#+BEGIN_SRC text
Old way: Read 2000-line file -> mental parse -> Edit
New way: orgx peek (50 tokens) -> orgx get ref (100 tokens) -> orgx set ref (0 tokens)
#+END_SRC

Core module: =pkg/= - parser, IR, commands
Entry point: =cmd/orgx/main.go=

* Design Principles

Accumulated wisdom from dev sessions. Read before making changes.

** Immutable Rules
#+BEGIN_QUOTE
1. READS NEVER WRITE - no implicit mutations during get/peek/find
2. WRITES ARE EXPLICIT - require --yes in non-interactive mode
3. REFS HAVE POLICIES - stable (::ID:) vs fragile (::/path, ::H:hash)
4. OUTPUT IS DETERMINISTIC - sorted, stable schema, no randomness
5. GRAMMAR IS NOUN-VERB - =orgx <noun> <verb>= with legacy aliases
#+END_QUOTE

** Ref Philosophy
- =::ID:= refs are stable (survive renames)
- =::/outline= and =::H:hash= are fragile (break on edits)
- Write commands should warn on fragile refs
- Agent-friendly: stable refs enable repeatable workflows

** Parser Decisions
- go-org = 80/20 org support, pure Go, batch-only
- goldmark = full GFM, batch-only
- tree-sitter = deferred (grammar immaturity, CGO overhead)
- Position tracking via lineTracker workaround

** Agent-First Philosophy
- Token efficiency over human convenience
- Composable commands (pipe-friendly)
- JSON output for machine consumption
- Human aliases preserved for convenience

** I/O Model
- stdout = data (text slice or JSON)
- stderr = UX (warnings, prompts, progress, diff previews)
- Rule: in =--json= mode, stdout MUST be valid JSON only

** Output Size Controls
Every command must support agent-friendly truncation:
- List commands: =--limit=, =--max-depth=
- Slice commands: =--max-bytes=, =--max-lines=, =--context=
- =--full= disables truncation (danger: huge output)

* Command Reference (Quick)

#+BEGIN_SRC text
orgx peek <path>              # Structure only (low tokens)
orgx get <ref>                # Specific section
orgx find <query> --in <dir>  # Search across files
orgx set <ref> [flags]        # Modify heading
orgx ls [path]                # List files with stats

Noun-verb equivalents:
  file outline = peek
  heading view = get
  heading set = set
  heading list = find
  file list = ls
#+END_SRC
